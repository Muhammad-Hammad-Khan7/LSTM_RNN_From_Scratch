# LSTM & RNN From Scratch

This repository contains an implementation of Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks to understand how sequence models work internally.

The goal of this project is to explore the fundamentals of recurrent neural networks, understand how LSTMs handle sequential data, and learn the concepts behind memory and long-term dependencies.

## 📌 Topics Covered

- **Recurrent Neural Networks (RNNs):** Understanding sequential data processing and hidden states.
- **Long Short-Term Memory (LSTM):** Understanding how LSTMs manage information over time.
- **Sequence Modeling:** Learning how neural networks process ordered data.
- **RNN vs. LSTM:** Exploring the differences between standard RNNs and LSTM architectures.
- **Implementation from Scratch:** Building a practical understanding of recurrent architectures.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Deep Learning Fundamentals

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Muhammad-Hammad-Khan7/LSTM_RNN_From_Scratch.git
cd LSTM_RNN_From_Scratch
```

### 2. Create a Virtual Environment

```bash
python -m venv env
```

Activate it on Windows PowerShell:

```powershell
.\env\Scripts\Activate.ps1
```

### 3. Install Dependencies

Install the libraries required by your implementation:

```bash
pip install numpy jupyter
```

If your code uses additional libraries, install those as well.

### 4. Run the Project

To open the notebook:

```bash
jupyter notebook LSTM_RNN_From_scratch.ipynb
```

To run the Python script:

```bash
python LSTM_RNN_From_scratch.py
```
